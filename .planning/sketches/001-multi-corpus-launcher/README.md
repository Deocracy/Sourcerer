# Sketch 001: Multi-Corpus Launcher

## Design Question

The daily entry point: you open Sourcerer and want to be back inside your last corpus in one action, with the other corpora (and their pending-contradiction state) visible but secondary.

## How to View

open .planning/sketches/001-multi-corpus-launcher/index.html

## Variants

- **A: Continue Hero + Grid** — a large "Resume" hero for the last-opened corpus above a card grid of the rest; new-corpus is a dashed card.
- **B: Rail List + Resume Panel** — corpus list in a left rail (status dot + recency), main panel shows the selected corpus's stats, recent activity, and Resume / open-side-by-side actions.
- **C: Command Palette** — near-empty home; Ctrl+K palette with the last corpus pre-highlighted so plain Enter resumes it; Shift+Enter opens side-by-side.

## What to Look For

- Which gets you back into RMS Titanic fastest without feeling cramped?
- Does the pending-contradictions signal (the amber chips) earn its place on the launcher, or is it noise here?
- B's recent-activity feed: valuable context or clutter before you've even opened the corpus?
- C is fastest for keyboard users but hides corpus state — is that trade acceptable?
