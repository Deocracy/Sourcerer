<!-- Seam contract this plan DEFINES; 03-02 (Dock/shellStore) and 03-04 (layouts) consume it. -->

WorkspaceRecordV1 shape (the ONE unified record, D-02/D-09/D-10):
  schemaVersion: number            // starts at 1 (LATEST_SCHEMA_VERSION)
  dockTree: unknown                // dockview api.toJSON() output (opaque to this module)
  rail: { railMode, railWidth, railOrder, leftRailPinned }   // shellStore persisted subset
  savedLayouts: Record<string, { id, name, record: Omit<WorkspaceRecordV1,'savedLayouts'> }>  // empty {} at v1
  instanceState: Record<string, unknown>   // instanceId-keyed slot, EMPTY until Phase 5 (D-10)
  restoreCanary?: boolean          // crash-on-restore guard, re-homed from Dock.tsx CANARY_KEY

registration seam (breaks the workspaceStore<->Dock/shellStore import cycle — workspaceStore
must NOT static-import Dock.tsx or shellStore.ts; consumers register live getters instead):
  registerStateSources(sources: {
    getDockTree: () => unknown | null;         // Dock.tsx registers dockApi.toJSON()
    getRail: () => WorkspaceRecordV1['rail'];   // shellStore registers its live subset
  }): void

Exported functions consumers call:
  loadWorkspaceRecord(): Promise<WorkspaceRecordV1>   // always resolves to a valid record (migrated or DEFAULT)
  saveWorkspaceRecord(record): Promise<void>
  scheduleWorkspaceSave(): void        // debounced 300ms; reads registered getters at flush time, not call time
  DEFAULT_WORKSPACE: WorkspaceRecordV1 // Wiki+Library (D-05), reused by reset (D-03) and fallback
</interfaces>
