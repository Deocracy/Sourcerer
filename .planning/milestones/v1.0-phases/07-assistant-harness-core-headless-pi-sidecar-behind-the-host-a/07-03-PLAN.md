<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Webview → Rust command | invoke() args (message, sessionId, modes) cross from renderer into the host |
| Rust → Node child process | Rust controls the spawned command line and env (secret material passes here) |
| Sidecar stdout → Rust parser | External process output parsed as JSON, forwarded to the webview |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-10 | Elevation of Privilege | Node child spawned with a model-/webview-controlled command or args | mitigate | Command path and args are Rust-constants (fixed `node` + fixed sidecar entry path); webview never supplies the executable or flags, only prompt/session/mode data written as JSON on stdin |
| T-07-11 | Information Disclosure | API key / env leaking through Rust logs or Channel | mitigate | Sidecar env is set by the sidecar's own .env (plan 07-01), not passed as loggable args here; stderr pump must not log env; Channel forwards only sidecar protocol events (no env) |
| T-07-12 | Denial of Service | host_ai hanging when sidecar is stuck/dead | mitigate | write_line error → error+done degrade (D-06); bounded per-turn timeout guarantees termination; setup spawn-failure does not abort launch |
| T-07-13 | Tampering | Malformed/oversized sidecar stdout line | mitigate | Parse each line defensively (skip unparseable lines); id-scoped dispatch ignores events with unknown/absent ids |
| T-07-SC | Tampering | New Cargo deps (tokio / tauri-plugin-shell if used) | accept | Mainstream, widely-audited crates from crates.io on Tauri's own dependency tree; no niche/unvetted crate introduced |
</threat_model>
