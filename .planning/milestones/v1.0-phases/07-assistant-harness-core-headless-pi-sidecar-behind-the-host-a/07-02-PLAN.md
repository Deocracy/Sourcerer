<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Sidecar → Databasise REST (127.0.0.1:9621) | Untrusted-content boundary: retrieved wiki text flows back into the LLM context (prompt injection) |
| LLM tool-call args → REST endpoint | Model-chosen params reach a whitelisted read surface |
| Session JSONL files ← turn content | User + model text persisted to app-data disk |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-05 | Tampering (prompt injection) | Databasise tool output re-entering the model context | mitigate | Tool results are returned as plain text clearly labeled `HTTP <status>` from an external source; whitelist is READ-only (resolve/query/list) so injected instructions cannot trigger writes; 4000-char truncation caps blast radius. Residual injection risk accepted for local single-user research use |
| T-07-06 | Elevation of Privilege (tool-scope escape) | Model reaching non-whitelisted Databasise endpoints | mitigate | Only four read endpoints generated as tools; `/wiki/preview` and all write/edit routes are never surfaced; research is the only mode with tools (D-04) |
| T-07-07 | Denial of Service (unreachable backend) | Databasise down / SSRF-adjacent hang | mitigate | 240s AbortSignal timeout + try/catch honest-degrade (D-06); base URL hardcoded to loopback 127.0.0.1:9621, not model-controlled (no SSRF pivot) |
| T-07-08 | Path Traversal | sessionId used to build a JSONL filename | mitigate | Sanitize/validate sessionId (allow only `[A-Za-z0-9_-]`); reject or hash ids containing path separators before joining the session dir path |
| T-07-09 | Information Disclosure | Session JSONL contents in app-data | accept | Local single-user desktop app; files live under OS app-data with normal user perms; no additional encryption this phase |
</threat_model>
