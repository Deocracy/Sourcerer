<objective>
## Phase Goal

**As a** scholar reading an assistant reply, **I want to** see the assistant's proposed edits as a
distinct serif-italic quote block I can approve/diff/reject with a keystroke, and turn an approved
proposal into a Home card, **so that** the assistant's suggestions become reviewable, actionable
artifacts instead of buried prose.

Add ASST-02: a pure client-side proposal parser (`proposalParse.ts`, D-02 — no new `host.ai()`
event shape) that scans the FINAL accumulated assistant text (on `done`) for a narrow marker
convention and returns a `Proposal | null`. Render matches as `proposal-quote` blocks (14px serif
italic) with a `[y] approve / [d] diff / [n] reject` action row and keyboard handling on the
focused proposal. Approving publishes the proposal text to `shellStore` and surfaces the
＋MAKE CARD affordance that writes `pendingCardMint` — the producer half of the D-06 assistant→Home
link (Home consumes it in Plan 06-06).

Purpose: ASST-02 proposals + the D-06 mint producer.
Output: `proposalParse.ts` (+test), grown proposal UI in `AssistantPanel.tsx`.
</objective>
