Pointer-capture analog (src/shell/useRailDrag.ts onResizePointerDown) — CRITICAL: the rail uses
`ev.clientX - navLeft` (grows rightward from the LEFT edge). The assistant is the RIGHT panel —
MIRROR to `hostRect.right - ev.clientX`. Do NOT copy the rail formula verbatim.

Recovered thresholds (RESEARCH Pattern 2 — use as-is):
```typescript
export type AsstSnap = { mode: "closed" } | { mode: "open"; width: number } | { mode: "full" };
const HIDDEN_W = 6;   // matches --asst-closed-w
const CLOSE_AT = 180; // drag narrower than this -> closed
const FULL_AT = 620;  // raw drag distance from host right edge -> full
export function snapWidthToAsstMode(raw: number, hostWidth: number): AsstSnap {
  if (raw > FULL_AT) return { mode: "full" };
  const clamped = Math.max(HIDDEN_W, Math.min(hostWidth - 160, raw));
  if (clamped < CLOSE_AT) return { mode: "closed" };
  return { mode: "open", width: clamped };
}
```
shellStore actions available after Plan 06-01: `setAsstWidth(w)`, `setAssistantOpen(open)` (both persisted);
reads: `useShellStore(s => s.asstWidth)`, `useShellStore(s => s.assistantOpen)`.
Default reopen-from-closed width: 280 (`--asst-width-default`).
</interfaces>
