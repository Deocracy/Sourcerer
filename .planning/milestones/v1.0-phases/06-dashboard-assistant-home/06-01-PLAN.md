Extend the shell store and the unified persistence record with the cross-surface state that the
Dashboard Assistant and Home surfaces both depend on. This is the Wave-1 contract layer: every
downstream Phase-6 plan reads or writes these fields, so they are defined once here to avoid four

consumes).

Home card mint) a single, conflict-free state seam.
