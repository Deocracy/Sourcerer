    per-task-commit sampling rate `02-VALIDATION.md` specifies. Default (no
    flag) runs both.

    Exit 0 with `diff-theia-core: PASS -- zero changes inside @theia/*`, or
    exit 1 with `diff-theia-core: FAIL -- <what differed>` and the diff output
