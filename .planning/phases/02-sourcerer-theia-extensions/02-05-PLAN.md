<objective>
Ship the visually-inert customization seam R4a names: a runtime user CSS layer
that is empty by default and hot-reloads when written, and a privileged JS layer
whose DI binding does not exist unless a build-time developer flag is set.

Purpose: CUST-01's whole guarantee is that turning the seam on changes nothing
until the user puts something in it. CUST-02's whole guarantee is that a release
build cannot be talked into executing a JS file from disk by any runtime input.

and a working positive control for the flag-off proof.
