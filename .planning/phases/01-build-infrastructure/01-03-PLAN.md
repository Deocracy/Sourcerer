<objective>
Materialize the pinned Firefox ESR source into `upstream/` with one documented
command, then prove the `firefox` dev shell can compile it — a full,
non-artifact build of stock 153.1.0esr producing a launchable browser.

Purpose: BUILD-02, and ROADMAP success criterion 2.
Output: `scripts/fetch-upstream.sh`, a materialized `upstream/` at tag
`FIREFOX_153_1_0esr_RELEASE`, and a green `scripts/smoke-firefox.sh`.

D-11 makes the full compile the acceptance proof deliberately: an artifact build
downloads prebuilt Gecko and proves almost nothing about the shell's C++/Rust
toolchain, and the cbindgen/rustc FFI drift class of failure (PITFALLS #2) is
only detectable by a real compile. This phase is first in the roadmap precisely
because that toolchain is the project's highest unknown; deferring the proof
would mean discovering it while it already blocks branding work.
</objective>

    `toolchain-baseline.txt` regeneration, not a manual `cargo install`. A

    drift risk gets reintroduced.
