<assumption_delta_decision>
**Noun now primary:** the *branding variant descriptor* (a record carrying a
variant's binary path, `.desktop` path, `config.status` path, `brand.ftl` path
and expected `-brand-full-name` together).

**Decision:** `promote`.

**Rationale:** `verify-branding-identity.mjs` was generalized from one variant
to two by parameterising `--bin` / `--desktop` / `--config-status`
independently. Surface 4 was left behind because nothing structurally forced it
to grow a flag -- the exact "second case introduced, original abstraction not
re-asked" seam. Adding `--brand-ftl` as a fourth independent flag would close
this instance and leave the seam open for the next surface. Promoting the
descriptor to primary makes variant knowledge a single record that a new
surface must extend, and collapses the aggregator's release invocation to
`--variant release`. Existing per-path flags are retained as overrides, so this
is a strictly additive promote with no caller breakage.

**Advisory only.** This checkpoint informs and records; it does not block. The
optional contract test it suggests -- "every identity surface reads its value
from the variant it was pointed at, for every supported variant" -- is
implemented as Task 2's cross-variant positive control, registered in the phase
aggregator so it goes red the instant a future surface reintroduces the
singular assumption.
</assumption_delta_decision>

Resolve every path constant from the selected variant's record, keeping the
existing per-path flags as explicit overrides that win over the descriptor:
`BIN_PATH` from `--bin` else the record's `bin`; `DESKTOP_FILE_PATH` from

`checkDesktopEntry()`'s `stockControl` shape. When set, the function reads the
*other* variant's `brandFtl` (the one descriptor record that is not the
selected variant) while keeping the selected variant's expected value. Add
`brand-full-name` to `CONTROLLABLE_SURFACES` and wire the new branch into
`runPositiveControl()` alongside the existing four. This single control proves
both axes at once: that the path is honored (a wrong file goes red) and that
the comparison discriminates (a wrong value goes red). A stock-value-only
control would not have caught CR-01, because CR-01's *value* was correct and
only its *path* was wrong.

trimmed line while the subsequent anchored regex matches the untrimmed line, so

line once and match the regex against the trimmed form.

description names the descriptor and the `--variant` selector rather than a
