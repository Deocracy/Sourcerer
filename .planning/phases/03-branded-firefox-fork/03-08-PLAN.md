Add an `--interrupt-self-test` mode to `scripts/verify-endpoints.sh` that
proves the Task 1 fix by sending a real signal to a real running control, not

Implement `run_interrupt_self_test` as follows. Before anything else, take its
own independent guard copy of `BRANDING_PREF_FILE` and record the file's
sha256 — this guard is the self-test's own safety net and is restored
unconditionally at the end, so a self-test that FAILS reports a failure rather
than leaving the real binary corrupted. Register the guard with
`track_temp` so it is cleaned up.

Launch `bash "$0" --layer 3 --positive-control` under `setsid` so the control
script becomes the leader of its own process group — the same idiom
`scripts/verify-phase-03.sh` already documents and uses, and necessary here
because the control backgrounds a browser of its own that a bare PID kill would
orphan. Wait long enough for the control to have written the mutated pref file
and entered its 35-second capture window; poll for the mutation rather than
sleeping blind — check the destination file for the appended
`media.gmp-gmpopenh264.enabled` pref, giving up with a clear failure after a
bounded number of one-second polls. Once the mutation is observed, send SIGINT
to the whole group with a negative-PID `kill`, then `wait` for the group leader.

After the group has exited, compare the destination file's sha256 to the
recorded pre-run value. Equal bytes is the PASS condition and the only PASS
condition; unequal bytes is a FAIL that must print both the expected and the
observed digest and the diff of the file against the guard copy, so the failure
is diagnosable. Then restore the guard copy unconditionally regardless of
outcome, and re-verify the digest after restore before returning.

Register `--interrupt-self-test` in the arg-parsing loop as a mode flag, and
in the driver block dispatch to `run_interrupt_self_test` instead of the layer
loop when it is set. It is mutually exclusive with `--layer` and
`--positive-control`; combining them must fail loudly. Add it to the `HELP`
text with a one-line note that it interrupts a real control on purpose.

In `scripts/verify-phase-03.sh`, append `verify-endpoints-interrupt-self-test`
to the non-`--quick` `CHECKS` block, invoking
`bash <repo>/scripts/verify-endpoints.sh --interrupt-self-test`. It dispatches
through the existing `bash */*` branch and so inherits the aggregator's own
`setsid` group handling.

Fix WR-02 in the same file: the fallback branch of the `case "$cmd"` dispatch
invokes a statically-known shell-function name through the shell's eval

needs arguments must add a wrapper function, not smuggle a command string.
