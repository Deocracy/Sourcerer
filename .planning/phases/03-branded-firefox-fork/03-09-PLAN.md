  <action>
Add a consistency gate that fails whenever the shipped allowlist and the
requirement documents disagree about which Mozilla hosts are carved out.

Implement the logic once as an inner helper taking an allowlist path as its
argument, following `check_allowlist_schema()`'s existing shape: a `node -e`
one-liner receiving paths as `process.argv` entries, printing a labelled
PASS/FAIL line, and exiting 0/1. The helper parses the allowlist, selects every
entry whose disposition is allow and whose host ends in the `mozilla.com` or
`mozilla.net` domain, and for each such host requires a whole-token occurrence
in both `.planning/ROADMAP.md` and `.planning/REQUIREMENTS.md`.

Whole-token matching is load-bearing, not a nicety: a plain substring search
would let `cdn.mozilla.net` pass vacuously on the strength of
`content-signature-2.cdn.mozilla.net` being documented. Match with a regex that
requires the character on each side of the host to be absent or outside the
hostname character class (ASCII letters, digits, dot, hyphen), so a host is
only satisfied by its own name, never by being a suffix or prefix of a
different documented name.

Guard against a vacuous pass: if the filtered set is empty, that is a FAIL with
a message saying the filter matched nothing, not a PASS. Report the count of
hosts checked and the count of documents each was found in, and emit any
violation list in sorted order so two runs on unchanged input produce identical
output.

Expose two argument-free wrappers for the `CHECKS` array — 03-08's dispatch
guard rejects any function-branch entry carrying arguments, so the entries must
be bare names. `check_allowlist_doc_consistency` calls the helper against the
repository's real allowlist. `check_allowlist_doc_consistency_self_test` writes
a temp copy of the real allowlist carrying two planted allow entries and
requires the helper to reject it: one host that is documented nowhere
(`sourcerer-selftest-control.cdn.mozilla.net`), and one that is a proper suffix
of two genuinely-documented hosts (`cdn.mozilla.net`) — the second is what
proves whole-token matching rather than substring matching. The self-test
passes only when the helper exits non-zero and its output names both planted
hosts. Register the temp copy with the script's cleanup so an interrupted
self-test leaves no residue, and never write to the real allowlist.

Append both wrappers to the `CHECKS` array. Put them in the shared block
alongside `allowlist-schema` rather than the non-`--quick` block: neither reads
a binary or launches a browser, so both belong in the fast path that `--quick`
also runs.
  </action>
