<objective>
Close GAP-1 from 06-HUMAN-UAT.md: the Dashboard Assistant (right rail) resize does not
match the demo prototype — the grip drag is janky (the panel does not resize until the
pointer is released) and the open/close toggle does not work.

Two concrete root causes are confirmed by inspection and must be fixed:

1. The title-bar right toggle button in RailToggleButtons.tsx is wired to
   `shellStore.getState().cycleRailMode()` — the LEFT rail action — so clicking it cycles
   the left rail and never touches the assistant. It must control the assistant, mirroring
   the prototype's `toggleRight` -> `cycleRight` (closed -> open -> full bounce).
2. useAssistantResize's `handleMove` updates only `liveSnap` (which drives the "LET GO TO
   SNAP" cue) but never a live width; AssistantPanel renders `style={{ width: asstWidth }}`,
   and `asstWidth` is written only on pointerup. So the panel snaps to its final width on
   release instead of following the pointer — the reported jankiness.

Purpose: make the right-rail resize/toggle feel identical to the prototype's
`startRightResize` / `startRightPull` / `cycleRight` logic (the UX source of truth).
Output: fluid live resize, a working right toggle, prototype-faithful snap cues, with
persisted width unchanged.

Requirement: ASST-03 (assistant resize with snap-to-close and expand-to-fullscreen).
</objective>
