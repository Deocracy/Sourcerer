<objective>
Stand up the Node Pi sidecar as a headless process: embed `@earendil-works/pi-coding-agent` with a lean baseline prompt (D-10), the mode registry + runtime toggle plumbing (D-02/D-04), its own `.env` config (D-08), and a newline-delimited JSON stdio protocol that streams Pi events out. This is the first Node runtime in the project and the core of the assistant harness.

Purpose: The harness must run behind `host.ai()` with the token cost living in tool schemas, not prose. This plan proves the embed streams and the mode seam is real, leaving file-backed sessions (D-09) and Databasise tools (D-03) as placeholders that plan 07-02 fills.
Output: A runnable `sidecar/` that, given `{"type":"prompt",...}` on stdin, streams `text_delta`/`done` events on stdout; in-memory sessions and an empty research tool set for now.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Rust host → Node sidecar (stdio) | Rust writes prompt JSON to sidecar stdin; sidecar output is trusted-local but must be parsed defensively |
| Sidecar env → process | CEREBRAS_API_KEY and provider config enter via sidecar/.env (secret material) |
| npm registry → build | Third-party Pi packages are executed code (supply chain) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-SC | Tampering | npm install of @earendil-works/pi-* + TypeBox | mitigate | Task 1 blocking-human legitimacy gate before install; pin exact approved versions; never auto-approve |
| T-07-01 | Information Disclosure | CEREBRAS_API_KEY in sidecar/.env and logs | mitigate | `.env` gitignored + `.env.example` only; the sidecar MUST NOT echo the key or full env into any stdout protocol event or error message |
| T-07-02 | Denial of Service | A turn error crashing the sidecar process | mitigate | Every turn wrapped in try/catch emitting `error`+`done`; process stays alive (D-06 degrade begins) |
| T-07-03 | Elevation of Privilege | Pi builtin tools (bash/edit/write) mounted by default | mitigate | `noTools: "builtin"` drops all builtin filesystem/shell tools; only mode-gated customTools reachable (spike 001 landmine) |
| T-07-04 | Tampering | CLAUDE.md/AGENTS.md auto-injected into every prompt | accept→mitigate | `noContextFiles: true` via DefaultResourceLoader + cwd set to sidecar dir; test asserts CLAUDE.md sentinel absent from prompt |
</threat_model>
