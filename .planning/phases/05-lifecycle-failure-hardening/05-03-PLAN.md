<recorded_decisions>
Discretionary choices locked (CONTEXT.md "Claude's Discretion"):

- **Chord (D-118):** Ctrl+Alt+Shift+D, expressed as the accel/alt/shift modifier
  set with key `D`, registered as a XUL key element marked reserved so a focused
  content browser cannot swallow it. Research confirmed zero three-modifier
  chords are claimed anywhere in the pinned Theia packages, so this collides with
  nothing Theia owns. The same chord closes the layer when it is already open.
- **Refresh cadence:** snapshot on open, plus a close control. No live polling
  loop — the surface exists to be read and pasted into a bug report, and a
  ticking log while the reader is trying to read it is worse, not better.
- **Layout:** a definition-style list of the seven fields, then the recent log in
  a monospace, scrollable block, then the close control. Same dark background,
  light text and layer geometry as the loading and error layers; a stacking index
  above both so it is readable over either.
- **Identity source (D-119):** brand name and vendor from the running
  application-info object, and version from the build's display-version constant
  — the same constant the browser's own support page shows, so the repointed
  check keeps comparing against the same file it compares against today.
- **Startup identity sentinel:** the shell writes the identity object to stdout
  once at startup, from the same accessor the layer renders. This is what makes
  the repointed branding check deterministic and headless-safe; it does not
  replace the layer, and the check asserts the two agree whenever the chrome
  driver is available.
</recorded_decisions>
